Settings

1. Your profile saved once, used in every interview

Who you are. The answers speak as you and only use experience written here, so be specific: roles, projects, numbers, the stories you like to tell, your strengths, the languages you code in.

2. This interview change before each one

Company, role, round type, job description, interviewer names, anything you know about what they care about.

3. AI model

Create one at console.groq.com → API Keys. It starts with gsk_.

qwen/qwen3.8-27b can read screenshots. If you switch to a text-only Groq model, use "Type a question" instead of screenshots.

Thinking counts toward this limit. Groq's free tier rejects requests above about 1000 tokens per minute, so keep 1000 unless you've upgraded.

Ollama on this PC: http://localhost:11434/v1 · OpenRouter: https://openrouter.ai/api/v1 · LM Studio: http://localhost:1234/v1

Ollama examples: qwen2.5vl:7b, llama3.2-vision, gemma3:12b. Pull one first with ollama pull qwen2.5vl:7b.

Windows encryption isn't available, so keys are stored only lightly obscured on this PC.

4. Hotkeys

Format: CommandOrControl+Shift+Space, Alt+Q, F8. They work even when another app is focused.

5. Screen sharing off by default

When this is on, Windows leaves the answer window out of screen shares and recordings, so it does not appear when you share your entire screen. It stays visible on your own monitor so you can read it, and its taskbar button is removed too (the taskbar is part of a full-screen share). It needs Windows 10 version 2004 or newer.

This PC's Windows build can't hide a window from screen capture, so this setting has no effect here.
